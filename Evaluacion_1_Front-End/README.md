# Portafolio Web - Front-End
## Descripción
Este proyecto corresponde a la evaluación 1 de programación  Front-End, donde se pide crear una página web utilizando HTML y CSS.
## Tecnologías utilizadas
- HTML5
- CSS3
- Flexbox
- Grid
## Características
- Diseño responsivo (tablet y móvil)
- Uso de etiquetas semánticas
- Galería de proyectos
- Formulario de contacto
